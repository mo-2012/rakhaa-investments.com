# رخاء للاستثمارات والاستشارات المالية والاقتصادية — ملفات الموقع

موقع ثابت (Static) ثنائي اللغة عربي/إنجليزي. لا يحتاج Node ولا PHP ولا قاعدة بيانات.

## التشغيل محليًا

افتح `index.html` مباشرة، أو — وهو الأفضل لأن بعض المتصفحات تحجب الملفات المحلية — شغّل خادمًا بسيطًا من داخل المجلد:

```bash
python3 -m http.server 8000
```

ثم افتح `http://localhost:8000`.

## النشر

ارفع **محتويات هذا المجلد** إلى جذر الاستضافة (public_html أو ما يعادله).

- `CNAME` — للنشر على GitHub Pages بنطاق مخصص. احذفه إن كنت تستخدم استضافة أخرى.
- `.htaccess` — إعدادات الضغط والتخزين المؤقت على Apache. تجاهله على Nginx أو Netlify أو Vercel.
- `sitemap.xml` و `robots.txt` — عدّل النطاق داخلهما إن تغيّر.

## بنية الملفات

```
index.html              الصفحة الرئيسية
library.html            المكتبة القانونية (22 ملف PDF)
Library.html            تحويل للمسار القديم
service-1..8.html       صفحات الخدمات الثماني
*.pdf                   ملفات المكتبة
assets/css/main.css     نظام التصميم بالكامل
assets/js/app.js        الهيدر، القائمة، الحركات، اللغة، نموذج التواصل
assets/js/library.js    بحث وتصنيفات المكتبة
assets/js/i18n.js       كل النصوص بالعربية والإنجليزية
assets/img/             الصور (webp مع بديل jpg)
favicon.svg / .ico      الأيقونات
```

## تعديل النصوص

كل الكلمات المعروضة موجودة في `assets/js/i18n.js` بمفتاح لكل نص وله نسختان: `ar` و `en`. عدّل النسختين معًا.

## نموذج التواصل

يُرسل إلى Formspree على النقطة `https://formspree.io/f/mlgwdajk` (موجودة في `index.html` داخل `<form id="contactForm">`). لتغيير الجهة المستقبلة، بدّل هذا الرابط فقط.

## اللغة

تُحفظ في كوكي `rakhaa.lang`، ويمكن فرضها بالرابط `?lang=en` أو `?lang=ar`.

## قسم المشروعات

القسم مبني في الكود لكنه مخفي لعدم وجود بيانات حقيقية. لإظهاره تُضاف بيانات المشروعات (الاسم بالعربية والإنجليزية، السنة، التصنيف، الصورة) ويعاد توليد الصفحات؛ عندها يظهر القسم ويظهر "مشاريعنا" في القائمة تلقائيًا.

## ملاحظات تقنية

- التصميم يعتمد الخصائص المنطقية (`margin-inline`, `inset-inline`) فلا حاجة لنسخة منفصلة للـRTL.
- الحركات تُلغى تلقائيًا لمن يفعّل `prefers-reduced-motion`.
- الصور تُحمَّل بصيغة WebP مع بديل JPEG عبر `<picture>`.
